Las guías, los contratos de hardware y los README de cada app están disponibles
en ambos idiomas. Los registros históricos tienen resúmenes en español y
conservan el detalle original en inglés. Cada registro describe las fuentes y
el firmware de su fecha; algunos usan atajos y direcciones de versiones
anteriores. Generá la
distribución actual con `build-and-flash.sh` y usá sus direcciones para instalar.
